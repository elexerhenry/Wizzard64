# INSTRUCTIONS

1. First, download and install Visual Studio Code by Microsoft if you haven't already.

2. Go to the Extensions tab and install the extension Live Server. Then, open the Wizzard64 folder in VS Code, and at the top click Manage, and trust the publisher (this allows you to use the emulator), then at the bottom right, click Go Live, and the emulator should be running! (To open the emulator in Safari, go into settings and make sure that Safari is your default browser (at least when opening it)).

Important: At any point when the emulator is running, whatever state it's in (running a ROM, menu, boot up, etc.), if VS Code gets closed and you try to click on anything, load anything, etc. the emulator will crash. You can minimize the VS Code window to save space, that won't affect it at all.
